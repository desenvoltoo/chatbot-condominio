Prezado(a) responsável técnico(a),

Estamos integrando a Central Inteligente de Autoatendimento WhatsApp para a nossa administradora de condomínios.
Para homologarmos a comunicação via API com seu sistema, precisamos das seguintes definições técnicas:

---

1. DISPONIBILIDADE E DOCUMENTAÇÃO DA API
- O sistema possui API REST (ou Web Services) disponível para integração externa?
- Onde podemos acessar a documentação técnica dos endpoints (Swagger, Postman Collection ou portal)?
- A administradora já possui acesso liberado a essa API no plano contratado, ou é necessária a contratação de algum módulo adicional?

2. AUTENTICAÇÃO E CREDENCIAIS
- Qual é o método de autenticação utilizado pela API?
  [ ] Chave de API estática (x-api-key ou token)
  [ ] OAuth 2.0 (Client ID / Client Secret / Bearer Token)
  [ ] Usuário e Senha com geração de token de sessão
- Como é feito o isolamento por condomínio? (Token único ou individual?)

3. CONSULTA DE MORADORES E UNIDADES (LGPD)
- Existe endpoint para buscar titular/morador pelo CPF/CNPJ?
- O retorno informa a lista de condomínios, blocos e unidades vinculadas a esse CPF?
- É possível obter o número de telefone celular cadastrado para conferência de segurança?

4. MÓDULO FINANCEIRO: EMISSÃO DE BOLETOS E PIX (PRIORITÁRIO)
- Existe endpoint para consultar os boletos em aberto (a vencer e vencidos) de uma unidade ou morador?
- Quando o boleto está vencido, a API permite gerar 2ª via atualizada com recálculo automático de juros e multa?
- O que a API retorna na consulta do boleto?
  [ ] Linha digitável / Código de barras (texto para copiar e colar)
  [ ] Código Pix Copia e Cola (chave dinâmica / payload EMV)
  [ ] Link direto do PDF ou arquivo em Base64 para envio no WhatsApp
  [ ] Data de vencimento e valor original/atualizado

5. OUTROS RECURSOS (RESERVAS E OCORRÊNCIAS)
- Existe endpoint para consultar disponibilidade de áreas comuns (salão de festas, churrasqueira) e realizar agendamentos?
- Existe endpoint para abertura de ocorrências/chamados de moradores (com envio de texto e fotos anexas)?

6. AMBIENTE DE TESTES (SANDBOX) E RATE LIMIT
- É fornecido um ambiente de testes (Sandbox / Homologação) com dados fictícios?
- Há limite de requisições por minuto/hora (Rate Limit)?

Perguntas Frequentes de Gestores de Condomínio

Existe algum risco de banimento do WhatsApp da administradora?

Não há risco. O sistema funciona estritamente no modelo receptivo (inbound), ou seja, é o morador quem entra em contato com o condomínio para solicitar o serviço. As políticas da Meta penalizam envio de spam e mensagens em massa não solicitadas, mas estimulam e priorizam canais de atendimento e autoatendimento ao consumidor.

E se o morador estiver com várias cotas atrasadas ou em cobrança jurídica?

O robô possui uma trava inteligente de inadimplência. Se o morador possuir mais de 2 cotas em aberto ou estiver com status de "Cobrança Jurídica" no seu ERP, o sistema bloqueia a emissão automática do boleto comum e transfere o atendimento diretamente para o setor de acordos/jurídico da sua administradora, evitando que ele pague apenas o mês atual e ignore a dívida antiga.

Como o robô atende moradores que possuem mais de uma unidade ou vaga de garagem?

Ao digitar o CPF, o sistema lista automaticamente todas as unidades vinculadas àquele proprietário (ex: Apt 101, Apt 404 ou Vaga 12) em um menu interativo, permitindo que ele escolha com 1 clique de qual unidade deseja emitir a cota condominial.

Podemos fazer um período de teste/piloto na nossa carteira?

Com certeza. Recomendamos iniciar com um piloto de 15 dias em 2 ou 3 condomínios selecionados da sua carteira. Dessa forma, você e os síndicos validam a satisfação dos moradores e o alívio imediato na sua equipe antes de estender para os demais prédios.
